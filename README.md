# FILA.CALC

Красивый калькулятор стоимости 3D-печати на русском языке.

## Что считает
- стоимость филамента;
- электричество;
- амортизацию / износ принтера;
- запас на расходники и брак;
- ручную работу;
- дополнительные расходы;
- наценку;
- прибыль;
- цену за грамм и цену за час.

## Как запустить
Просто открой `index.html` двойным кликом.

## Как выложить бесплатно на GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи `index.html`, `style.css`, `script.js`.
3. Открой Settings → Pages.
4. В Source выбери ветку `main`, папку `/root`.
5. Сохрани — GitHub выдаст ссылку на сайт.

## Настройки
Все введённые значения сохраняются в браузере через localStorage.
